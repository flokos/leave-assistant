## Decisions and deviations (also in the docs)
1. **One justification document** for all technologies (user decision during planning), with the evidence of the
   milestones; doc 02 keeps versions and licences, the ADRs the large decisions.
2. **Platform settings hold tenant defaults only** (one typed row instead of the planned key/value table); provider
   configuration stays in the environment.
3. **`tenants.settings.max_upload_mb` is superseded** by the security policy's upload limit (M5) and not editable by
   companies.
4. **One platform page** combines the new-company defaults and the security defaults (instead of two pages).
5. **GLiNER/XLM-R not evaluated**: the measured errors were removable deterministically (doc 08 §7.7, ADR-0017).
6. **Gemini spot check, not a measurement**: one day's free quota covered two scenarios (R-03).
7. **The restore check runs before the stack starts** (scheduled jobs change rows at start).
8. **Google manual checklist not run**: it needs the user's Google OAuth client (doc 10 §9).

## Problems found and how they were solved

| Problem | Resolution |
|---------|------------|
| Clean clone: `make models` ran inside the running api, loaded every model under its 3.5 GB limit, and the api was OOM-killed | one-off container with its own limit; the prefetch frees each model; candidate A only with `ALL=1` |
| Clean clone: `make bootstrap` came before `make models` in the guide; the embedded worker processed the seeded documents without models and 5 of 17 failed after three attempts | the guide and the README download the models first; `make retry-failed` re-queues failed versions |
| Clean clone and the corpus reindex: `make ingest` started a second worker inside the api next to the embedded one; two ingestion children exceeded the limit and the api was OOM-killed | with `WORKER_MODE=embedded` the drain waits for the embedded worker |
| Clean clone: `NAME=   # comment` lines in `.env.example` — Docker Compose read the comment as the value; `OAUTH_REDIRECT_BASE_URL` broke the calendar consent, `GROQ_API_KEY` held a comment | comments moved above the empty values; a rule in the file's preamble; the configuration reference attaches them |
| Backup archives were owned by a remapped uid (100999) | archives streamed through stdout/stdin, owned by the calling user |
| The restore check reported 13 conversations and 4 audit rows fewer/more | the scheduled jobs (archived-conversation cleanup, retention scan) ran at start; the check now runs before the start and matched 9/9 |
| The M9 harness never wrote `verifier_exhausted` (the M9 files had been back-filled) | derived from the `fallback` outcome; the verifier's problems recorded too |
| S19: two live runs returned `not_found` for an argument the model chose | the name lookup gained a distinctive-word step; the captured run passed "Οικονομικές Υπηρεσίες", which resolved and was denied by scope |
| Mistral free plan answered 429 during several live runs | repeated with slower pacing; reported separately as provider outages |
| A misleading test expectation in the department lookup ("sales people") | step 3 matches the complete name "Sales" first; replaced by a real ambiguity |
