## Problems encountered and how they were solved
1. **`git mv` on an untracked file** fails in a fresh repository — renamed with `mv` before the first commit.
2. **`corepack pnpm` fails on this host** (corepack 0.24 / Node 22.22) — the project standardises on npm (host npm 9.2,
   npm 11 inside `node:24-alpine`); Dockerfile, Makefile, CI and docs updated. Deviation from the M0 plan, recorded here.
3. **npm peer-dependency triangle:** TypeScript 7 is rejected by `typescript-eslint@8` (`<6.1`), TypeScript 6 is rejected
   by `openapi-typescript@7`; TypeScript **5.9** satisfies every tool. The same conflict made `npm ci` fail inside the
   image until the lockfile was regenerated.
4. **`vite.config.ts` uses `process.env`** → `@types/node` added to `tsconfig` types.
5. **Ant Design under jsdom** needs `window.matchMedia` and `ResizeObserver` stubs (`src/test-setup.ts`).
6. **structlog processor typing** under mypy — processors are typed with `structlog.types.EventDict/Processor`.
7. **Bundle size warning (872 kB)**: expected before route-level code splitting; follow-up for M3 when real pages arrive.
8. **`--scale worker=0` with explicit service names** is rejected by Compose v5 ("disabled"); `up api frontend` simply
   does not start `worker` (it depends on `api`, not the reverse) — `make up-staged` fixed accordingly.
9. **First readiness probe after Keycloak start** timed out at 2 s on this loaded host (`ReadTimeout`) and succeeded on
   the next probe; the per-check timeout is now a setting (`READINESS_TIMEOUT_SECONDS`, default 5 s).
