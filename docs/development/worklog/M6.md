## Decisions and deviations (also written into the docs)
1. **Answers stream after citation verification**, not token by token from the model (plan decision 4).
2. **Business intents get a templated pointer** to the matching page until the M7 tools exist.
3. **Reranker default stays candidate B.** Candidate A is wired and downloaded but unusable on this host (below).
4. **10 rerank candidates at 256 tokens** instead of 20 at 512, for NFR-PERF-01 (doc 05 §6.7).
5. **τ = 0.5** for candidate B, calibrated on the scenarios (doc 05 §6.7). P02 (dress code) scores 0.509 and is a live
   probe without a deterministic outcome.
6. **`authored_by_viewer` re-identification rule**: what a user typed is restored in their own view (doc 08 §7.4).
7. **Answer language is enforced deterministically**: Greek question, Greek answer, even from English sources (user
   requirement during M6; S03/S04 are the cross-lingual cases).
8. **Gemini thinking is bounded** (`thinking_level=low`, 1,024-token allowance on top of the answer budget) and a
   token-limit stop is invalid output (doc 04 §4.1).
9. **Groq default models** are `llama-3.1-8b-instant` for the fast role and `llama-3.3-70b-versatile` for answers.
   The plan named `llama-3.3-70b-versatile` / `openai/gpt-oss-120b`. Classification and query rewriting are small
   tasks, so the fast role takes Groq's lowest-latency tool-use model, and the answer role keeps the 70B model that
   doc 02 proposed as the default. Both are settings. Not verified live: the Groq signup was blocked, and Mistral
   replaced Groq as the second provider (addendum).
10. **Langfuse** is a masked callback behind `LANGFUSE_ENABLED`; live traces need the M9 `observability` profile.

## Addendum 2026-11-06: Mistral replaces Groq as the second provider
The user's Groq signup was refused (`signup_blocked`, Groq's anti-abuse check), so Groq could not be tested live.
Free alternatives were compared on official pages: GitHub Models is retired (30 July 2026), Cerebras and NVIDIA offer
trials only, Cloudflare Workers AI allows about 49K output tokens a day, OpenRouter's `:free` models 50 requests a day.
The user chose Mistral's free "Experiment" plan. **Deviation from brief §4.2 (Gemini + Groq), approved by the user.**
Groq stays implemented and selectable: `LLM_PROVIDER_ORDER` defaults to `gemini,mistral,groq` and providers without a
key are skipped.

- **Adapter** `infrastructure/llm/mistral.py` on `langchain-mistralai` 1.1.6 (strict JSON-schema output; the resolver
  added only it and `httpx-sse` 0.4.3 to the lock). The client's retry setting counts total attempts, so it is set to 1:
  the router owns retries. HTTP errors map through the shared classifier (429/5xx transient, 401/403/404 fatal).
  7 adapter tests run against a mocked transport.
- **Models, probed with the key** (rate-limit headers per model on the free plan):

| Model | Requests/min | Tokens/min | Verdict |
|-------|--------------|------------|---------|
| `mistral-small-2603`, `mistral-medium-2604`, `magistral-*` | 0 | 0 | not on the free plan |
| `mistral-large-4` | 50 | 20K | always reasons (`reasoning_effort` ≥ low), used the whole 700-token budget; also needs `top_p=1` with temperature 0 |
| `ministral-14b-2512` | 30 | 938K | **answers** (`MISTRAL_MODEL`) |

- **Live smoke forced onto Mistral** (`make chat-smoke ARGS="--order mistral"`): 5 / 5 correct and in the question's
  language, 0 failovers. Answered turns took 6.2–7.7 s (S01, the first turn after a restart, 67–85 s while the

- **Forced failover** (`make chat-smoke ARGS="--gemini-timeout 0.01"`): 5 / 5 answered by Mistral. `provider_events`

- **Markdown in answers**: Mistral bolded words (`**κανονικής**`), and the chat shows plain text. System prompt v2
  forbids Markdown, and `strip_markdown` removes emphasis and heading marks before verification. The rerun was clean.
- Unit tests after the addendum: backend 747 passed, frontend 36 passed; lint clean.

## Problems encountered and how they were solved
| Problem | Resolution |
|---------|------------|
| **api crashed with SIGILL (exit 132)** during the chat smoke; not reproducible on demand (80 fresh processes clean) | `faulthandler` captured `mkl_vml_kernel_sTanh_Z0HAynn`: MKL's vector `tanh` on the AVX-only CPU, reached from BERT's pooler (e5, during the input screen) and later from the XLM-R classification head (reranker). `MKL_CBWR=AVX` and `MKL_ENABLE_INSTRUCTIONS` did not prevent it. e5 drops its unused pooler and both models rewrite `tanh` as `2·sigmoid(2x) − 1` (vectors identical, scores within 1.5e-8, no speed cost). Afterwards 0 crashes in 15 fresh stress processes, the live smoke, integration, e2e and 40 perf turns (R-27) |
| Input screening ran e5 on the event loop | `ingress` and Presidio detection run in worker threads |
| Gemini answered S01/S04 with "insufficient evidence" although retrieval found the right sections | Two causes. The drafts were cut off mid-sentence: thinking tokens used up the 700-token cap, and the truncated JSON still parsed. Fix: bounded thinking, a thinking allowance and `MAX_TOKENS` → invalid output. Gemini also wrote grouped markers `[1, 2, 3]`: they are split before verification, and prompt v3 asks for one number per bracket |
| Gemini omitted inline markers but listed citations | prompt v2 asks for inline markers; `attach_declared` appends valid declared citations |
| An English answer to a Greek question (cross-lingual sources) | deterministic language check in `verify_citations`; cross-lingual smoke cases S03/S04 |
| `gemini-3.6-flash` free-tier quota: `429 RESOURCE_EXHAUSTED` after two back-to-back smoke runs | the router retried and surfaced `chat/provider-unavailable` (no second provider); R-03 updated |
| Gemini `503 high demand` | handled by the router's jittered retry |
| Reranking 17 pairs took 7–8 s | fewer, shorter pairs (decision 4); ONNX would be 1.5–2× faster but onnxruntime is not in the image; PyTorch int8 quantisation hit the same SIGILL |
| A merged context group cited its first chunk, not the relevant one | cite the best-scoring chunk of the group |
| The fake classifier matched "book" inside "handbook" | word-boundary patterns |
| Users saw neutral labels for values they had typed themselves | `authored_by_viewer` rule (decision 6) |
| Chat page crashed with "l is not a function" in Chromium | `scrollIntoView` returns a Promise in newer browsers and an arrow-expression effect returned it as cleanup; block-bodied effect + regression test |
| E2E specs assumed `/leave` as the landing page | they navigate to `/leave` after sign-in |
| Scenario fixture: pytest-asyncio scope mismatch, then `DetachedInstanceError` | module-scoped loop; run fields copied out of the session |
| The first live search after start timed out in the integration test | e5 loads lazily: background warm-up at api start, 90 s timeout on that test |
| ruff `ASYNC109` on a `timeout` parameter; `ChatGroq` field aliases | renamed to `deadline_seconds`; `model`/`api_key`/`timeout` |
| Edits silently not applied after ruff reformatted lines | patch scripts assert that the old text exists |
| `make contract` fails while the regenerated files are uncommitted | expected: it diffs against git; regenerated twice, then committed |
