## Decisions recorded (plan decisions 1–12, all implemented)
Scope boundary with M5 (no-op scanners, review endpoints without UI, no supporting documents); `platform.jobs`
without RLS; ML handlers in a child process in both worker modes (`API_MEMORY_LIMIT=3G` when embedded); models in
the `models` volume via `make models`; multipart uploads with pure-Python magic sniffing and key-only idempotency;
`app.f_unaccent` for the simple FTS leg; hybrid retrieval without reranker/context budget; search + citations under
`/documents`; ADR-0027 permissions in Python and SQL with a parity test; re-indexing from the stored structure;
rendered seed corpus with the superseded handbook pair; `ml` marker for model-dependent tests.

## Problems encountered and how they were solved
| Problem | Resolution |
|---------|------------|
| Docling 2.147 raises at pipeline construction when `do_ocr=True` and the tesseract binary is missing (developer hosts) | the parser checks `shutil.which(tesseract_cmd)` and falls back to text-layer parsing with a warning; OCR is verified in the container (`make test-ocr`, live test) |
| `AcceleratorOptions` moved to `docling.datamodel.accelerator_options`; `TableStructureOptions` has no `do_cell_matching` on the base class | import from the new module; option dropped |
| `unaccent()` is STABLE, generated columns need IMMUTABLE | `app.f_unaccent` SQL wrapper (IMMUTABLE, PARALLEL SAFE) with the dictionary qualified |
| The `models` volume (created at M0) is root-owned; the api runs as uid 10001 → HF cache `PermissionError` | `make models` chowns the volume once; the Dockerfile creates `/models` for the app user |
| e5-small prefers same-language passages: a Greek query scored an irrelevant Greek passage above the relevant English one | the `ml` test compares against an irrelevant passage of the *other* language (doc 02 §12 set-up); ranking quality is M9's business (reranker) |
| TanStack `onError` has four arguments; ruff ASYNC240 on blocking file calls inside async code; ruff reformatting invalidating patch anchors | signatures fixed; `asyncio.to_thread` for hashing, temp-file unlinks annotated; patches applied with formatting-tolerant matching |
| jsdom `File` is not a Node `Blob`: undici cannot read a jsdom `FormData` body, so `request.formData()` in the fetch mock threw and the modal showed the generic error | the Vitest upload test scripts the response and observes the parts through a `FormData.prototype.append` spy |
| antd `Modal` keeps its DOM until the close animation ends (jsdom never finishes it) | the success-path upload test renders its own page instead of reusing the refused modal |
| Playwright/Make targets written with relative paths broke when a parallel tool call changed the working directory | absolute paths everywhere (`make -C`, `docker compose -f /abs/...`) |
| One ingestion child exited with SIGILL (-4) on the DOCX job's first attempt (no OOM: cgroup peak 2.4 GB) | the retry/backoff path did its job (second attempt succeeded in 56 s); the same file parses in 12.8 s with `parse_check`; root cause not isolated — tracked as a follow-up (doc 13) |

## Changes versus the plan
- Search lives in `db/repositories/chunks.py` (both legs are SQL inside the request transaction) instead of a
  separate `infrastructure/vector/` package; the `VectorIndex` port of doc 05 §7 is introduced with the Chroma
  adapter in M9 (doc 03 §4.1 tree amended by this note).
- Department notices are uploaded from the UI by managers (own department); HR uploads them through the API only
  (the UI has no department picker for HR yet — M5 ACL/permissions UI).
- `document_versions.parsed_structure jsonb` became `extracted_object_key` (the normalised block tree is kept in
  object storage next to the original; doc 07 amended).
- Review endpoints exist without a UI (M5 brings the queue and quarantine screens together with risk scoring).
- Markdown/TXT documents report `pages = NULL` (Docling's non-paginated backends); citations then show no page.
- Version `attempts` is tracked on the version row as well as on the job (operator visibility in the status table).
- NFR-PERF-02's text-PDF target is not met on the 4-core host (273.5 s vs 180 s); recorded with the per-stage costs and
  mitigation options rather than tuned blindly (ADR-0015 keeps Docling for structure; M9 decides with the evaluation data).
- The seed corpus facts follow the seeded business data (annual 20 d, sick 10 d, carry-over 5 d until 31 March, the
  3-day sick acknowledgement cap, the 2026 holiday lists); doc 11 S08 is realised as handbook v1 "25 days" (superseded)
  vs v2 "20 days".
