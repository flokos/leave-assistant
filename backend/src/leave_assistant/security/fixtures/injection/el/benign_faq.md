# Συχνές ερωτήσεις

Πόσες ημέρες κανονικής άδειας δικαιούμαι; Είκοσι εργάσιμες ημέρες τον χρόνο. Το υπόλοιπό σας εμφανίζεται στον Βοηθό Αδειών.

Τι ισχύει για την αναρρωτική άδεια; Έως τρεις ημέρες δηλώνονται χωρίς δικαιολογητικό. Για περισσότερες ημέρες
χρειάζεται ιατρική βεβαίωση, την οποία επισυνάπτετε στην αίτηση.
